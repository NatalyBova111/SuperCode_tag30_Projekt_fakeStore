SuperFakeStore — Mini Shop (Vite + TypeScript)

Небольшой учебный интернет-магазин на базе FakeStore API.
Показывает список товаров, поиск по названию, сортировку и фильтрацию по категориям (чипы).
Дизайн — как в задании: оранжевая панель, 3-колоночная сетка карточек, зелёные цены, оранжевые кнопки.

Стек
- Vite + TypeScript
- FakeStore API (https://fakestoreapi.com)
- Чистые HTML/CSS (без фреймворков)

Возможности
- Загрузка товаров с FakeStore API
- Фильтр по категориям (чипы)
- Поиск по названию
- Сортировка: по цене ↑/↓, по названию A–Z
- Рендер карточек с картинкой, ценой, рейтингом и кнопкой Add to cart
  (для ДЗ — без настоящей корзины; кнопка даёт визуальный отклик)


Установка и запуск
1) установить зависимости
npm install
2) запустить dev-сервер
npm run dev
3) открыть URL из консоли (обычно http://localhost:5173)

Эндпоинты API
- GET /products — список всех товаров
- GET /products/categories — список категорий
Документация: https://fakestoreapi.com/docs

Как это работает (поток данных)
1. init()
   - Загружаем категории → рисуем «чипы» (кнопки) и заполняем скрытый <select id="category">.
   - Загружаем товары → сохраняем в allProducts → запускаем applyFilters().
2. applyFilters()
   - Берём allProducts, применяем:
     - фильтр по категории (значение — из скрытого селекта),
     - поиск по названию (значение — из #search),
     - сортировку (значение — из #sort).
   - Результат кладём в viewProducts и вызываем renderProducts().
3. renderProducts()
   - Если список пуст → показываем «Keine Ergebnisse.» и выходим.
   - Иначе собираем HTML карточек и вставляем в #grid.

---Что в HTML----

HTML (каркас/контейнеры)
HTML — это «скелет» страницы: фиксированные контейнеры и элементы 
управления, к которым будет «прикручиваться» логика.
- Заголовок: <h1 class="logo">SuperFakeStore</h1> 
Статичный заголовок. Он не зависит от данных, поэтому держим его в HTML (лучше для доступности/SEO).

- Оранжевая панель .toolbar из двух рядов::
ряд 1:
    <input id="search"> — поле поиска (пользовательский ввод).
    <select id="sort"> — выбор сортировки.
ряд 2:
    подпись “Filter by Categories:” — статичный текст.
     <div id="catChips"> — пустой контейнер, в который TS динамически вставит «чипы» категорий (кнопки).

  -  скрытый селект   <select id="category" class="visually-hidden"> — , в нём мы храним текущее значение категории (удобная опора для логики фильтрации).
- Контейнеры: #status — статус загрузки/ошибок, #grid — сетка карточек
    Основной контент:
    <div id="status"> — место для сообщений «Loading…»/ошибка.
    <section id="grid"> — пустая «сетка», в которую TS дорисует карточки товаров.
Почему эти элементы в HTML?
Они задают макет/точки крепления: ввод (поиск/сортировка), статичные подписи, и контейнеры, куда мы будем рендерить динамику. Так проще подключать события, и страница имеет понятную структуру даже без JS.


----TypeScript (логика/динамика)----

- Типы данных (Product, Rating)
  
- Запросы к API (FakeStore)
  Мы используем fetch(...).then(...).then(...):
    GET /products/categories — получаем список категорий;
    GET /products — получаем массив товаров.  
- Состояние: allProducts / viewProducts
  let allProducts: Product[] = [];  // все товары с API
  let viewProducts: Product[] = []; // текущий отфильтрованный список для рендера

- Рендер чипов категорий и карточек
  Категории приходят с сервера, поэтому рисуем кнопки динамически:
  создаём кнопки в #catChips;
  при клике на чип выставляем значение в скрытом #category и вызываем фильтрацию.

-  Фильтрация и сортировка (applyFilters)
Берём allProducts → фильтруем по:
категории (значение из #category),
поиску (строка из #search),
сортируем (по #sort),
результат рендерим.
- Рендер карточек (renderProducts)
Создаём HTML карточек и вставляем в #grid.
Есть «гард»: если список пуст — выводим «Keine Ergebnisse.».
- Обработчики событий
input на поле поиска → applyFilters()
input на селекте сортировки → applyFilters()
клики по чипам категорий → меняем категорию и applyFilters()
- Безопасность строки (escapeHtml)
Если вставляем текст в innerHTML, экранируем спецсимволы, чтобы исключить XSS.
- Инициализация (init)
Загружаем категории → рисуем чипы →
Загружаем товары → запускаем applyFilters() → карточки появляются в гриде.
(Почему это в TypeScript?
Потому что всё это зависит от данных (API), меняется во время работы и требует логики (фильтры/сортировка/события). Хранить такие блоки в HTML невозможно — их нужно генерировать и обновлять программно.)

Ключевые фрагменты кода

1) Простая загрузка (в стиле документации API)
fetch('https://fakestoreapi.com/products')
  .then(res => res.json())
  .then((products: Product[]) => {
    allProducts = products;
    applyFilters();
  })
  .catch(err => console.error(err));

1) Гард на пустой список
// Если после фильтров нет товаров — показываем заглушку и выходим.
if (list.length === 0) {
  grid.innerHTML = `<p style="color:#666;margin:8px 0;">Keine Ergebnisse.</p>`;
  return;
}

1) Экранирование при вставке через innerHTML
function escapeHtml(s: string): string {
  return s.replace(/[&<>"']/g, m =>
    ({ "&":"&amp;","<":"&lt;",">":"&gt;",'"':"&quot;","'":"&#39;" }[m] as string)
  );
}
